# MetWet Website

This is the official website for the MetWet - Metal Weight Calculator app, designed for hosting on GitHub Pages.

## How to Deploy to GitHub Pages

1. **Create a new repository** on GitHub (e.g., `metwet-app`).
2. **Upload the contents** of this `metwet-website` folder to the root of your new repository.
3. **Enable GitHub Pages**:
   - Go to your repository **Settings**.
   - Navigate to **Pages** in the left sidebar.
   - Under **Build and deployment**, set the source to **Deploy from a branch**.
   - Select the `main` branch and `/ (root)` folder.
   - Click **Save**.

Your website will be live at `https://<your-username>.github.io/metwet-app/`.
